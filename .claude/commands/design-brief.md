Create a design brief for: $ARGUMENTS

Read `vapi-network/04-design/brand-guidelines.md` and `asset-specs.md`.

Produce:
- **Asset type** and which master template it uses
- **Dimensions** and format (per asset-specs)
- **Exact copy** for every text element, with character counts
- **Layout notes** — hierarchy, what dominates, what's secondary
- **Colour and type** per the brand kit
- Accessibility check: contrast ratio, minimum legible size on mobile
- Watermark: "vAPI Network" — confirm placement

Save to `vapi-network/04-design/briefs/YYYY-MM-DD-<slug>.md`.

Text on a LinkedIn image must be legible at thumbnail size. If the copy is too long
for the format, say so and cut it.
