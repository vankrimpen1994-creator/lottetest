# Week 0 Checklist — run this the day the trial is green-lit

Nothing publishes this week. This is the foundation, and skipping it is why most
LinkedIn launches stall around week five.

## Day 1 — Access & assets
- [ ] LinkedIn company page admin access granted
- [ ] Brand assets received: logo (SVG + PNG), fonts, colour hexes, existing deck
- [ ] Named content approver confirmed + 48h turnaround agreed
- [ ] Shared folder / Notion / Slack channel set up
- [ ] Analytics access: page, website, CRM
- [ ] CRM field created for LinkedIn-sourced leads

## Day 1–2 — Fix the name problem _(do this first, it's free and time-sensitive)_
- [ ] Page name set to **"vAPI Network"** — never "VAPI" alone
- [ ] **Custom page URL claimed** before someone else takes it
- [ ] Tagline includes "onchain task market" so link previews disambiguate
- [ ] About section keyword-weighted: x402, agent payments, AI agent infrastructure, USDC, non-custodial
- [ ] Hashtag set locked: `#x402` `#agenticpayments` `#agenteconomy`. Never `#vapi`
- [ ] Standard bio line drafted for every employee profile

## Day 2–3 — Page & profiles
- [ ] Company page: banner, logo, tagline, About, Products, custom CTA button
- [ ] **Founder/exec profile overhauls** (≥2): headline, banner, About, Featured
- [ ] Founders briefed on the commenting routine (10/week) and shown how it works
- [ ] Employee advocacy list drawn up

## Day 3–4 — Design system
- [ ] 6 master templates built: quote, stat, carousel cover, carousel interior, clip frame, podcast announce
- [ ] Watermark placement locked
- [ ] Page banner + founder banners produced
- [ ] Contrast + thumbnail legibility checked on all six

## Day 4–5 — Content & podcast
- [ ] **30-day calendar drafted and approved in one batch** — so weeks 1–4 never wait on sign-off
- [ ] First 7 posts fully drafted
- [ ] Engagement target list built (20 accounts across ICP A/B/C)
- [ ] Podcast: name, cover art, format, recording stack
- [ ] **Guest pipeline 10 deep**, first 3 invites sent
- [ ] Tracking sheet live, baseline recorded

## Gate — don't start Week 1 until all of these are true
- [ ] Page is live, named correctly, custom URL claimed
- [ ] ≥2 founder profiles optimised and their owners have agreed to post
- [ ] 30 days of content approved
- [ ] Design templates exist
- [ ] Baseline metrics recorded
